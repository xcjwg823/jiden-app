# MOCHI — 15s Motion Reel

@mochi_diet_bichou のための 15 秒・縦型 (1080×1920 / 30fps) モーショングラフィックス。

| 時間 | シーン |
|---|---|
| 0.0–2.5 | もちキャラ（mochi_chara.png）が落下 → ぽよん！と弾んで、タイトル |
| 2.5–4.5 | 体重計ダイヤル＋オドメーターで **−19KG** |
| 4.5–8.0 | レシピ7品を0.5秒ごとにウィップカット（全てベクター作画） |
| 8.0–10.5 | 実際の投稿グリッドがパララックススクロール → プロフィールカード（69投稿 / 1.6万フォロワー） |
| 10.5–12.5 | 習慣：忙しいからパパッと／1品でも／健康美人 |
| 12.5–15.0 | エンドカード：フォロー → フォロー中 ✓ |

- `index.html` — ブラウザで開くとループ再生（決定論的 `render(t)`）
- `render.mjs` — Playwright で 1 フレーム 5 サンプルのモーションブラー付きで書き出し
- `audio.py` — 優しい BGM（オルゴール＋マリンバ, 120BPM, カットは全て拍に同期）と効果音を合成
- `mochi_reel.mp4` — 完成動画（音声付き）
